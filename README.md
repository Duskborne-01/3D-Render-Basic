# 3D Render Basic

A lightweight, foundational project demonstrating core concepts of 3D computer graphics and rendering from scratch. 

## 🚀 Features

- **Software/Custom Rasterizer or Basic Pipeline:** Built to showcase fundamental rendering calculations without heavy reliance on external heavy engines.
- **Geometric Transformations:** Implements translation, scaling, rotation, and projection matrices.
- **Lighting & Shading:** Basic implementation of lighting models (e.g., flat, Gouraud, or Phong shading).
- **Wireframe & Triangle Rasterization:** Draws basic shapes and meshes onto a 2D viewport.
